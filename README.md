## What it does

`main.py` writes one excuse to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> I didn't miss the deadline — I asked my autocomplete to finish the report, and it confidently wrote my resignation letter instead.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
